thread.add

Create a threaded comment on a cell or range.

Required fields - body - op - target

Optional fields - author - createdAt

Examples

{
  "op": "thread.add",
  "target": {

      "sheet": "Sheet1",
      "address": "F5"
    }
  },
  "body": "Cell comment"
}
