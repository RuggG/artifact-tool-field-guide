table.add

Create a table from a range.

Required fields - op - props - props.range

Optional fields - as - props.hasHeaders - props.name

Examples

{
  "op": "table.add",
  "props": {
    "range": {
      "sheet": "Inventory",
      "range": "A1:C3"
    },
    "hasHeaders": true,
    "name": "InventoryTable"
  }
}
