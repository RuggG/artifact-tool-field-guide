range.format.set

Apply formatting to a range.

Required fields - op - props - target

Optional fields - props.borders - props.columnWidth - props.fill - props.font - props.horizontalAlignment - props.numberFormat - props.rowHeight - props.verticalAlignment - props.wrapText

Enums - props.borders.preset: See enums. - props.fill.color.value: See enums. - props.fill.gradientKind: See enums. - props.fill.pattern.type: See enums. - props.horizontalAlignment: See enums. - props.verticalAlignment: See enums.

Examples

{
  "op": "range.format.set",
  "target": {
    "sheet": "Scorecard",
    "range": "A1:C1"
  },
  "props": {
    "fill": "accent1",
    "font": {
      "bold": true,
      "size": 14
    },
    "horizontalAlignment": "Center"
  }
}
